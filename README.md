# HMDT Remake

A modernized static remake of the abandoned HMDT design preview concept, rebuilt as a lightweight web app with updated material presets and item categories.

## Features

- Object selection for multiple armor and equipment silhouettes
- Texture presets with modern material finishes
- Accent color controls and profile styling
- Randomize button and shareable URL state
- Texture catalog page for reviewing all options

## Run locally

From this folder:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```

## Notes

The original site is used as inspiration and this project is a fresh implementation built for local previewing and further extension.
